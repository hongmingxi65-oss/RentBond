# Preset demonstration access

Demo entry: https://rentbond.vercel.app/demo

Type: **Read-only, completed Monad Testnet leases. No login or wallet required.**

The demo contains two real testnet outcomes from fictional scenarios:

1. Partial release plus dual-service timeout: 1,000 MockUSD funded; 100 accepted, 200 disputed; tenant withdrew 700 before resolution and another 200 after timeout; landlord withdrew 100. Final 900/100, all remaining balances zero.
2. Full refund: tenant withdrew all 1,000 MockUSD, all remaining balances zero.

Judges can expand the transaction evidence, open public explorer receipts, download the dated chain snapshot, and follow the separate new-lease entry. There are no shared accounts, private evidence files, wallet signatures or expiring sessions in the public demo. It is historical, not a live balance feed or a replayable lease. The primary/fallback award route is not represented as tested by these cases.
